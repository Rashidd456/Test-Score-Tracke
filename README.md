# Test Score Tracker

A web-based test score tracker built with Python and Streamlit.

## Features

- Add students
- Remove students
- Add scores
- Remove scores
- Display student scores
- Calculate averages and letter grades

## Built With

- Python
- Streamlit
- JSON
